# Reinforcement Learning on Highway-env

A Deep Q-Network (DQN) agent trained to drive autonomously on a simulated highway, with a safety-oriented variant using reward shaping.

## Overview

This project implements and compares two approaches on the [`highway-v0`](https://highway-env.farama.org/) environment:

1. **Core task** — a custom DQN vs. Stable-Baselines3 DQN, benchmarked on reward and collision rate.
2. **Safety task** — a safety-aware DQN trained with a reward shaping wrapper that penalises dangerous driving behaviours.

## Environment

| Parameter | Value |
|---|---|
| Environment | `highway-v0` (highway-env) |
| Observation | Kinematics — 5 vehicles × 5 features (presence, x, y, vx, vy) → 25-dim flat vector |
| Action space | DiscreteMetaAction — 5 actions: LANE_LEFT, IDLE, LANE_RIGHT, FASTER, SLOWER |
| Lanes | 4 |
| Traffic density | 50 vehicles |
| Episode duration | 40 steps |

## Installation

```bash
pip install -r requirements.txt
```

Requires Python 3.10+.

## Usage

### Core task

Train both agents:
```bash
python train.py
```

Evaluate and generate plots:
```bash
python run_eval.py
```

Checkpoints are saved under `results/dqn/` and `results/sb3/`. Training is skipped automatically if a checkpoint already exists.

### Safety task

Train the safety DQN:
```bash
python train_safety.py
```

Run safety evaluation across standard / dense / hard scenarios:
```bash
python run_eval_safety.py
```

Results are saved to `results/safety_eval/`.

## DQN Architecture

Both the custom and safety DQN use a 3-layer MLP:

```
Input (25) → Linear(256) → ReLU → Linear(256) → ReLU → Linear(5)
```

Key hyperparameters:

| Parameter | Value |
|---|---|
| Discount factor (γ) | 0.9 |
| Learning rate | 5e-4 |
| Batch size | 64 |
| Replay buffer | 15 000 |
| Target network update | every 200 steps |
| Epsilon decay | exponential, min = 0.05 |
| Episodes | 300 |

## Safety Reward Shaping

`SafetyRewardWrapper` subtracts a penalty from the base reward at each step:

| Penalty | Trigger | Magnitude |
|---|---|---|
| Collision | Terminal state | 2.0 |
| Tailgating | Front distance < 0.12 (normalised) | 1.5 × deficit |
| Lane change | Any lane change | 0.02 |
| Fast + close | vx > 0.32 and front distance < 0.10 | 0.5 |

Safety evaluation uses three traffic scenarios: **standard** (50 vehicles), **dense** (70 vehicles, tighter spacing), and **hard** (90 vehicles, very tight spacing, 60-step episodes).
